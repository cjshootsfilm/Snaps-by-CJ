SNAPS BY CJ — WEBSITE FILES

To preview:
1. Open the folder.
2. Double-click index.html.

To publish free with Cloudflare Pages:
1. Create a free Cloudflare account.
2. Open Workers & Pages.
3. Choose Create > Pages > Upload assets.
4. Upload this whole folder, or upload the ZIP file.
5. Choose the project name "snapsbycj" if available.

Before publishing:
- Replace the contact placeholder in index.html with your email or Instagram.
- You can add more images later inside the images folder.
